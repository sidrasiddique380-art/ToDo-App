# Todo List App

A tiny, dependency-free todo list. Just HTML, CSS, and JavaScript.

## How to run in VS Code

1. Open the `todo-app` folder in VS Code.
2. Easiest option: install the **Live Server** extension, right-click `index.html`, and choose **"Open with Live Server"**.
   - No extension? Just double-click `index.html` to open it directly in your browser — it works the same way.
3. Add tasks with the input box, check them off, or delete them with the ✕ button.

Your tasks are saved automatically in the browser's local storage, so they'll still be there next time you open the page.
